# KGHPPO-Attention（version 4）

在已有低层 PPO-Attention 上增加可训练的高层知识引导：**模糊知识 → 候选注意力 → 超网络 Q 融合 → 加权模仿**。低层使用单帧 364 维观测，高层使用四帧和候选特征。算法文件及入口沿用本目录，原版 `kghppo_attention/` 不变。

本版固定原始低层，启动后直接训练高层。历史模型和实验结果保留；修改前 v3 源码在 `runs/v4_frozen_low_20261105/source_v3/`。成功率由你运行完整训练和评估后确认。

## 启动

使用已安装 PyTorch/CUDA、NumPy、TensorBoard 的环境：

```bash
conda activate turtlebot3_ws
cd /home/hnu/turtlebot3_ws/src/paper_7/kghppo_attention_v2
python main.py --device cuda
# 显示二维仿真、在线地图、frontier、知识参考路径及两个首选候选
python main.py --device cuda --render on
# 完整恢复；训练种子与原配置一致
python main.py --checkpoint runs/<运行目录>/last.pt --seed 3
# 固定验证集与逐段诊断
python main.py --mode eval --checkpoint runs/<运行目录>/last.pt --trace on
# 定稿后的新独立测试集，固定 100 个任务
python main.py --mode eval --eval-suite test --checkpoint runs/<运行目录>/last.pt
```

默认预算 200000 个环境交互 step，全部用于训练高层；评估另行计数。每 10000 步保存并评估固定 100 任务，训练进程终端仅输出完整评估汇总及实际错误。2D 环境包含 U 型墙、死胡同、多房间、门洞及狭窄通道。

## 固定低层与目标

默认低层为本目录的 `runs/attention_paper/step_180000.pt`。`--low-checkpoint` 可以显式选择其他完整 PPO_ATTENTION v1 模型；加载后 Actor、模糊模块、超网络和 Critic 全部冻结，使用确定性动作，训练中不更新低层参数、引导下限或训练计数。

程序直接开始完整导航，已经删除低层适配、局部任务、能力门槛、课程采样及交接流程。高层的 200000 步预算从 0 开始。对照组可以直接使用同一个原始低层：

```bash
python main.py --seed 11 --guidance on
python main.py --seed 11 --guidance off
```

- 绿色星形为 **最终目标**，由场景初始化，在一个回合内保持不变。
- 紫色三角为 **当前子目标**，由高层选定，转换成世界坐标后固定到本段执行结束。
- 换子目标不重置机器人、不修改最终目标。只有完整导航结束或保存评估切换任务时才 reset。

候选覆盖 360°，保持 15 距离 ×15 方向共 225 个，最大采样范围 3.5 m。安全筛选检查从机器人到候选的整段直线走廊，包括终点的 0.15 m 安全圆。实现为胶囊形区域（矩形加两端圆盘）的射线相交，包含雷达后置 0.032 m 偏移和束间角度余量；遮挡或超出观测范围的走廊不可选。

最终目标在 3.5 m 内且整段走廊安全时，才替换最近的普通候选；小于 0.5 m 的精确终点也可选。目标被遮挡时保留原普通候选，不强制追踪终点。所有候选无效时明确报错，不使用隐藏的备用动作。

## 在线地图与知识

地图只接收 360 束雷达、真实扫描角度及自身里程计，不读取场景名称、边界或真实障碍。默认理想里程计与当前传感器模型；带漂移定位的真实部署需要另行验证。

- 0.1 m 栅格；射线空闲证据 −0.4、命中证据 +0.85，log-odds 限制在 ±4。
- 同帧同格更新一次，命中优先。距 3.5 m 最大量程不足 0.05 m 的读数不作为命中，避免将量程噪声画成障碍环。
- 已知占用格作 0.15 m 欧氏中心距离膨胀；只在已观测空闲格上搜索，八邻接且禁止对角穿墙。
- 目标已知可达则参考目标，否则参考 frontier；最小化 `已知路径长度 + 到终点直线距离 +2*(1−新颖度) − 信息收益`。信息收益为 1 m 半径内未知格比例。
- frontier 保持至接近 0.5 m、失效或终点已知可达。不存在可用路径时，路径特征显式无效，不从真实地图补齐。

路径知识只提供候选特征与偏好，最终子目标由融合 Q 值选择。奖励仍使用仿真真值地图的 A* 距离；窗口的青色虚线是**在线观测地图的知识参考路径**，不是奖励真值路径。灰色墙是仿真场景展示，不输入策略。

高层状态为 `1456 + 225*14 = 4606` 维。每个候选按以下顺序编码：

`x/3.5, y/3.5, length/3.5, sinθ, cosθ, exact_goal, alignment, euclidean_progress, clearance, opening, novelty, route_progress, route_valid, turn_ease`。

四帧编码为 `1456→256→128`，候选共享 `14→64→64`，知识偏置注意力后连接共享 Dueling 优势头和价值头，输出 225 个 Q 值。候选为 15 距离 ×15 方向，最大范围 3.5 m；安全直达的精确终点替换一个槽位，输出维度不变。

八条模糊规则：

|前件|后件|
|---|---:|
|精确终点|+4|
|已知路径进展高、净空足够|+2|
|已知路径进展高、转向方便|+1|
|已知路径进展高、候选较新|+0.5|
|已知路径进展低、非终点|−2|
|净空不足、非终点|−1|
|路径不可用、开口宽、候选较新|+0.5|
|路径不可用、方向接近终点、净空足够|+0.5|

路径可用性只启用/禁用规则。因此实际为 **15 个前件乘子＋8 个规则乘子＝23 个可训练标量**；原计划中的 19 个前件是计数错误。高斯中心 0/1、宽度 0.35，min 合取，乘子 `2*sigmoid(logit)` 初值 1，固定后件。知识分数为后件加权证据之和除以 4。

置信度用知识首选的覆盖度、规则一致性与有效候选分数差异，不是校准后的成功概率。高层沿用 `alpha=stopgrad(C)*(Omega+(1−Omega)*g)`；`Omega` 在 256 条 warmup 后的 2000 次高层决策中从 0.8 降至 0，保留学习到的知识影响。

TD 更新神经 Q、模糊与超网络；`stopgrad(alpha)*KL(stopgrad(P_K)||P_N)` 只更新神经 Q 和注意力。注意力知识偏置停止梯度。每条经验 4 次更新，200 组更新后同步完整目标网络，折扣 `0.99**(k/25)`。不增加 PER、多步回报或额外奖励。

## 结束、换点与恢复

成功为目标距离严格小于 0.1 m，雷达碰撞阈值 0.15 m，碰撞优先，800 步超时。

高层奖励保持 `100*成功 −100*碰撞 −0.1*k +5*最终目标A*距离改善`。普通子目标到达半径 0.3 m，进展阈值 0.05 m/15°、停滞窗口 3 s；精确终点为 0.1 m、0.01 m/5°、6 s。首次看见有效终点与首次进入终点 0.5 m 各触发一次重新选点，不强制选择终点。

新 checkpoint 标识 `KGHPPO_ATTENTION` version 4，保存固定低层完整状态、来源路径及文件 SHA-256、在线/目标高层、优化器、有效 Replay、训练计数及 RNG。Replay 保存采样时的完整候选特征，不用后来地图重算。恢复从新回合开始，不恢复机器人或在线地图中间状态。旧 v1/v2/v3 高层模型必须使用相应归档源码，不能把适配后的低层隐式带入新训练。v4 模型包含低层权重，恢复和评估不依赖原低层文件继续存在。新日志目录为 `runs/kghppo_attention_v4_<UTC时间>/`。

## 输出与实验口径

- `checkpoint_metrics.csv`：模型排名、训练步数、成功率和 SPL。
- `eval_tasks_step_*.csv`：每次完整导航验证的逐任务结果，含路径、SPL、子目标数、停滞、知识改变选点次数和漏选终点次数。
- `--trace on`：逐段首选、融合权重、终点标记、位姿、执行时长及奖励分项。
- TensorBoard 保留 episode reward、窗口三率、评估三率、高层引导权重、高层损失五组图。

验证集 seed 从 5000000 起、独立测试从 7000000 起，均不随训练种子变化。每五个任务轮换五场景。模型选择按验证成功率、SPL、训练步数降序；独立测试不能用于调参。

高层注意力、模糊知识、超网络融合和模仿机制保留。代码修改只做静态及小规模逻辑检查；完整训练与性能评估由你自行运行。

Gazebo 仍通过 `--backend gazebo --mode eval` 使用已有暂停/继续接口。部署构建自己的**观测地图**，不调用仿真真值奖励地图；ROS/Gazebo 由外部启动，训练使用自带 2D 仿真。隔离联调不修改用户正在运行的仿真。
